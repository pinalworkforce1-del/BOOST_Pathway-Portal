How to use this map

  • Use the Start Here row before entering the main BOOST experience.
  • Complete the four core modules in order: Discover, Reality Check, Career Mobility, and Decide.
  • If Module 4 recommends an applied career experience, that experience is highlighted on the map.
  • After the applied experience, return to your Career Coach to decide whether the strongest next step is work now, bridge, build, or more exploration.
Coach note: Northern BOOST is designed to support conversation, not automate decisions. Use the evidence to guide discussion with the participant rather than pushing a single pathway.
